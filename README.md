## 🔍 What is EDA?

**Exploratory Data Analysis (EDA)** is the process of analyzing and understanding a dataset before applying Machine Learning or statistical models.

EDA helps us answer questions like:

- What does the dataset contain?
- How many rows and columns are there?
- Which features are important?
- Are there missing values?
- Are there duplicate records?
- Are there outliers?
- What relationships exist between variables?
- What patterns and trends can we find?

## 💡 Why is EDA Important?

EDA is one of the most important steps in a Data Science workflow.

A good EDA process can help you:

✅ Understand your data  
✅ Find data quality problems  
✅ Detect outliers  
✅ Discover patterns  
✅ Identify relationships between features  
✅ Select useful features  
✅ Make better Machine Learning decisions  

> **Remember:** Better understanding of data → Better decisions → Better Machine Learning models.
